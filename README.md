# I Know Your Age

Age-guessing game for **iknowyourage.games**: answer questions about pop-culture memories and the game guesses your age.

- Static site, no build step: `index.html` + `assets/`
- 5 languages: English, 日本語， 简体中文， Español, Português — switch with the 🌐 button or `?lang=ja|zh|es|pt`
- 297 questions, adaptive 12–45 questions per game, confidence meter, memory-strata result chart and share card

Open `index.html` in a browser (or serve the folder with any static host) to play.
